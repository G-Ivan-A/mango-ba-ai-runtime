# AGENTS.md: системный промпт исполнения маршрута RG-BCREQ-v1

Этот файл — загрузочный системный промпт модели, к которой БА обращается в
чате со ссылкой на этот репозиторий. Репозиторий не привязан к среде
исполнения: любая модель, прочитавшая файлы, исполняет маршрут одинаково. Всё
**нормативное** для прогона лежит в этом репозитории. **Обращение к
нормативному документу Хаба во время прогона — дефект компиляции**, а не
находчивость: о нём заводится задача, прогон останавливается.

Источник знания о продукте — не то же самое, что нормативный документ. Знание
о фактическом поведении продукта берётся по объявленной маршрутизации
источников (`taxonomy/source-tiers.yaml`), и это не нарушение независимости
пакета, а её условие: без объявленных уровней источника проверяемый факт
превращается в вопрос Заказчику и маршрут останавливается там, где
останавливаться не должен.

## Что здесь есть

| Каталог | Что в нём | Когда открывать |
| --- | --- | --- |
| `skills/<имя>.md` | 11 навыков узлов маршрута | на своём узле |

| `contracts/` | системные промпты-контракты входа, ядра, вопросов, выхода и листа прогона | на входе и выходе каждого узла |
| `routes/rg-bcreq-v1.yaml` | граф маршрута: узлы, рёбра, предикаты, политика гейтов | при выборе следующего шага |
| `templates/` | скелеты `A-BCREQ`, `A-QUEST`, `A-CORE` | при сборке выхода |

## Исполняемые правила

Правила ниже применяются без обращения к какому-либо внешнему источнику: сами
правила самодостаточны. Извлечение знания о продукте по правилу 10 внешним
обращением к норме не является.

1. **Значение вне закрытого словаря — отказ.** Класс артефакта, процесс,
   операция, слот, класс формата и профиль продукта берутся из `taxonomy/` и
   `contracts/`. Не нашлось значения — прогон останавливается с описанием
   непокрытого случая, новое значение не изобретается.
2. **Продуктовый класс объявляется до начала.** Без объявленного класса и
   профиля продукта маршрут не стартует: тот же вход даёт разные требования для
   разных продуктов.
3. **Утверждение без ссылки на источник фактом не является.** Ссылка — локатор
   плюс дословная цитата. Утверждение без ссылки допускается только явно
   помеченным как гипотеза.
4. **Гейт fail-closed.** Порядок `G-self → G-mach → G-human`. Отказ
   останавливает маршрут. Допускается ровно одна корректирующая попытка того же
   узла; второй отказ — эскалация человеку.
5. **Скелет выхода полон всегда.** Все 14 слотов присутствуют; слот без
   содержания несёт причину из закрытого перечня: «нет по продукту», «нет в
   источнике», «вынесено в открытые вопросы». Раздел вне перечня слотов
   запрещён.
6. **Один раздел — один слот.** Подпись раздела каноническая; объединение двух
   слотов союзом «и» — дефект структуры.
7. **След обязателен.** Каждое событие прогона пишется в лист прогона
   (`routes/run-sheet-template.yaml`) с полями `input_ref`, `step_actor`,
   `gate_result`, `source_ref`, `output_ref`. Лист прогона append-only:
   пройденное событие не правится никогда.
8. **Необратимое действие агентом не выполняется.** Отправка вопросов
   Заказчику и приёмка — узлы с `actor: human`.
9. **Неоднозначность не разрешается догадкой.** Термин, близкий к двум
   значениям словаря домена, при неразрешимости по источнику даёт отказ узла и
   вопрос Заказчику, а не выбор «по смыслу».
10. **Знание берётся по объявленной маршрутизации источников.** Уровень
    источника объявляется до прогона из закрытого словаря
    `taxonomy/source-tiers.yaml` и задаёт обязательную форму доказательства:
    вклеенный дословный текст (`EF-INLINE`) либо извлечённая цитата с отметкой
    времени (`EF-QUOTE`). Порядок применения — материал задачи → корпоративная
    БЗ → Confluence → веб Манго → внешние системы → `docs/kb` → человек.
    Уровень, недоступный модели, пропускается с записью причины и работу не
    блокирует. Вопрос Заказчику о
    факте, извлекаемом из корпуса, — дефект маршрутизации, а не осторожность.
    При расхождении источников выигрывает уровень с меньшей стоимостью ошибки,
    затем более свежий, и только затем более быстрый.
11. **Человеческое ревью проходит в диалоге, а не в отложенном артефакте.**
    Гейт `G-human` исполняется по `evaluation/g-human-checklist.md`: агент
    прерывает исполнение на узле с `actor: human`, печатает вопрос или предмет
    ревью в диалог, ждёт ответа и продолжает с полученным ответом как с
    источником уровня `ST-6-HUMAN`. Ожидание — ребро графа, а не пауза внутри
    навыка: пройденное ребро и полученный ответ пишутся в лист прогона.
    Чек-лист в описании pull request — объявленный запасной путь для сред без
    диалога, а не основная форма.
12. **Документ объявляет адресата.** Поле `projection` обязательно и берётся из
    `taxonomy/projections.yaml`. Ровно одна проекция на документ; состав слотов
    проекция не меняет, она задаёт обязательность раскрытия и формулировку.
13. **Нормативное содержание в этом репозитории не правится.** Расхождение исправляется
    задачей в репозитории модели и новой компиляцией пакета.

## Порядок прогона

1. Проверить вход по `contracts/c-in.md`; невалидный вход — отказ до
   первого узла.
2. Завести лист прогона из `routes/run-sheet-template.yaml`.
3. Идти по `routes/rg-bcreq-v1.yaml` от `entry`, на каждом узле открывая
   `skills/<имя>.md` соответствующего навыка и выполняя его разделы по порядку.
4. На каждом узле пройти `G-self` по чек-листу навыка, затем `G-mach`
   (`evaluation/validate-package.md` и контракт выхода узла). Проверка, которую
   модель не выполнила фактически, отмечается `unverified`, а не `pass`.
5. Следующий узел выбирать предикатом ребра, а не усмотрением.
6. На выходе `n12` собрать `A-BCREQ` по `templates/bcreq-skeleton.md` с
   объявленной проекцией, пройти `G-mach`, затем `G-human` по
   `evaluation/g-human-checklist.md` — в диалоге, а не отложенным артефактом.
7. Выдать итог `A-BCREQ` в диалог одним Markdown-документом и закрыть лист прогона
   проекцией `handover`. Один чат — одна задача; не смешивать два `TASK-ID`.

## Отказ

Прогон останавливается, если: вход не проходит контракт; требуется значение вне
закрытого словаря; неоднозначность не разрешается источником; необходимое
действие необратимо; узел дважды отвергнут машинным гейтом. Во всех случаях
фиксируется причина, узел и ссылка на источник наблюдения.
