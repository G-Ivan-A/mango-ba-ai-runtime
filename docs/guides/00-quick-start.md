# Быстрый старт: первый результат за 5 минут

## 1. Клонируйте репозиторий

Установите [Git](https://git-scm.com/downloads). На Windows нажмите `Win`,
введите `PowerShell`, откройте приложение и выполните:

```sh
git clone https://github.com/G-Ivan-A/mango-ba-ai-runtime.git
cd mango-ba-ai-runtime
```

Ожидаемый результат: приглашение терминала заканчивается на
`mango-ba-ai-runtime`.

## 2. Проверьте пакет без Python

```sh
sh tools/validate-package.sh
```

Последняя строка должна начинаться с `G-mach: package accepted`.

## 3. Откройте репозиторий в GigaCode

Откройте проект по правилам вашей установленной версии GigaCode CLI. Актуальные
публичные материалы: [GigaCode в GitVerse](https://gitverse.ru/gigacode/) и
[поиск публикаций GigaCode на Habr](https://habr.com/ru/search/?q=GigaCode&target_type=posts).
Названия команд CLI могут меняться, поэтому в пакете не зафиксирована
непроверенная команда запуска. Убедитесь, что GigaCode видит корневой
`AGENTS.md` и `.agents/skills/`.

## 4. Запустите одну задачу в новом чате

Вставьте:

```text
Запусти RG-BCREQ-v1. TASK-0001: подготовь бизнес-требование для изменения
очереди контакт-центра. При ожидании больше 30 секунд предложить обратный
звонок. Заказчик: Иван. Проекция: V-BIZ. Используй доступные источники по
порядку из .hub-profile.json. Перед G-human остановись и задай вопрос.
```

Новый чат нужен для следующей задачи; не смешивайте два `TASK-ID`.

## 5. Получите результат

После согласования проверьте:

```sh
find runs -type f -maxdepth 3
```

Ожидаемый итог: `runs/RUN-....../A-BCREQ.md` и лист прогона рядом.
