# Быстрый старт: первый результат в чате модели

## 1. Откройте новый чат

Одна задача — один чат. Для следующей задачи откройте новый чат; не смешивайте
два `TASK-ID`.

## 2. Дайте модели репозиторий

Укажите ссылку на репозиторий, лучше на конкретный коммит:

```text
https://github.com/G-Ivan-A/mango-ba-ai-runtime/tree/<SHA>
```

Попросите модель перечислить прочитанные файлы. Если модель не может открыть
ссылку, вставьте или приложите `AGENTS.md`, `routes/rg-bcreq-v1.yaml`, нужный
навык из `skills/` и контракт из `contracts/`.

## 3. Запустите задачу

Вставьте:

```text
Прочитай AGENTS.md и запусти RG-BCREQ-v1. TASK-0001: подготовь бизнес-требование
для изменения очереди контакт-центра. При ожидании больше 30 секунд предложить
обратный звонок. Заказчик: Иван. Проекция: V-BIZ. Используй источники по
порядку из taxonomy/source-tiers.yaml. Перед G-human остановись и задай вопрос.
```

## 4. Получите результат

После согласования модель выдаёт `A-BCREQ` одним Markdown-документом и лист
прогона по `contracts/c-rk.md`. Сохраните их там, где принято в вашей работе.
