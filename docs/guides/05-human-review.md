# Согласование G-human

G-human нужен перед необратимым действием, для ответа Заказчика и перед
финальной приёмкой. Агент обязан остановиться в текущем чате.

## Пример

```text
Агент: G-human, RUN-0004, n7. Q-01: через сколько секунд ожидания предлагать
обратный звонок? Влияние: без ответа нельзя сформировать критерий. Ответьте
значением или напишите «отклонить».

Пользователь: Одобрить Q-01: 30 секунд.
```

После ответа агент записывает его как `ST-6-HUMAN`, проходит следующий узел и
показывает новый статус. Допустимые ответы:

- `Одобрить` — принять показанный результат;
- `Одобрить с изменением: ...` — принять только после явной правки;
- `Отклонить: ...` — остановить и зафиксировать причину;
- конкретный ответ на `Q-NN` — продолжить уточнение.

Не открывайте новый чат для ответа на G-human: потеряется связь с RUN-ID.
