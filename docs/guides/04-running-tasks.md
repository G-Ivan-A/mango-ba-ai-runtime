# Запуск задач в GigaCode

## Главное правило

Один чат GigaCode = одна задача. Новая бизнес-задача — новый чат и новый
`TASK-NNNN`. Ответ на вопрос G-human остаётся в том же чате.

## Новый запуск

1. Создайте новый чат в интерфейсе GigaCode.
2. Укажите `TASK-ID`, заголовок, заказчика, продукт и исходные данные.
3. Передайте данные одним из способов:
   - текст: вставьте его после `Исходные данные:`;
   - ссылка: напишите URL и разрешите соответствующий уровень;
   - файл: приложите файл и укажите его имя.
4. Укажите необязательные `projection`, `profile` и разрешённые уровни.
5. Напишите: `Запусти RG-BCREQ-v1 и остановись на каждом G-human`.

## Контроль источников

Агент идёт по уровням из `.hub-profile.json`. Сейчас уровни 1–4 явно
`out_of_slice`, потому что адреса и доступы не предоставлены. Для включения
уровня замените статус на `available`, добавьте locator/URL и предоставьте
доступ безопасным способом вашей организации. Не записывайте секреты в Git.

## Где результат

Итог: `runs/<RUN-ID>/A-BCREQ.md`. Если файла нет, спросите:

```text
Покажи текущий узел, последний гейт, причину остановки и ожидаемый путь файла.
```
