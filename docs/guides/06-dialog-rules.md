# Правила диалога с агентом

Это фразы пользователя, а не команды оболочки:

| Фраза | Результат |
| --- | --- |
| `Статус` | TASK-ID, RUN-ID, текущий узел, гейт и следующий шаг |
| `Покажи источники` | уровни, locator, цитаты и время извлечения |
| `Добавь источник: <URL/файл>` | новый источник текущей задачи |
| `Ответ на Q-01: ...` | данные для продолжения P-02 |
| `Одобрить` | прохождение текущего G-human |
| `Отклонить: <причина>` | остановка с записанной причиной |
| `Покажи результат` | путь и содержание текущего A-BCREQ |

Новые факты сопровождайте источником. Если это предположение, пишите
`Гипотеза:`. Не просите агента угадывать URL, секреты или продуктовые решения.

Для новой задачи откройте новый чат. Для дополнительных данных текущей задачи
оставайтесь в текущем чате и сохраняйте тот же `TASK-ID`/`RUN-ID`.
