При предварительной настройке шаблона доступен выбор только одной группы. В дальнейшем пользователь может выбрать другую группу сотрудников для мониторинга показателей.

Значения групповых показателей выводятся общие по выбранной группе. Значения персональных показателей выводятся по каждому сотруднику выбранной группы.
