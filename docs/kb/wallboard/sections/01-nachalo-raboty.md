# 1. Начало работы

> Трассировка: PDF §1 · сквозные стр. 3 · источники: ч.1 `kb/sources/wallboard/Programma-dlya-EVM-Wallboard-Mango-Office_v7.22.25.pdf` с.3.

Модуль Программа для ЭВМ "Wallboard Mango Office" отражает индивидуальные или командные рейтинги операторов, а также общие показатели подразделений в режиме реального времени. Доступ к модулю осуществляется по адресу tv.mango-office.ru.

Доступ к модулю есть у пользователей ВАТС с ролью Администратор. В противном случае пункт меню "Wallboard" не отображается.
