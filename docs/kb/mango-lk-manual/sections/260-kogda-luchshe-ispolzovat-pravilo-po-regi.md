#### Когда лучше использовать правило «По региону»

> Трассировка: PDF §4.5.19.4 · сквозные стр. 425-426 · источники: ч.2 `kb/sources/mango-lk-manual/LK_manual_v-125-281-566.pdf` с.145-146.

Правило «По региону» позволяет системе автоматически подбирать карусель номеров в зависимости от региона клиента. Система определяет регион клиента по набираемому номеру и использует этот параметр, чтобы выбрать карусель с номерами, принадлежащими тому же региону (если нет карусели с приоритетом выше и другими настройками).

Это особенно полезно для компаний, которые работают по всей России и хотят, чтобы каждый клиент получал звонок с локального номера своего региона — это повышает доверие и вероятность ответа.

Когда применять на практике

1. Для компаний с клиентами из разных регионов Если у вас федеральная база клиентов, настройка по региону поможет вызывать доверие у абонентов и повысить конверсию в ответ.

Пример:

Регион «Москва» звонки выполняются с московских номеров. o

Регион «Новосибирская область» звонки выполняются с номеров o 7383. Клиенты видят знакомый номер и с большей вероятностью берут трубку.

2. Для региональных представительств и филиалов Если у компании несколько филиалов, можно привязать звонки каждого офиса к своему региону.

Пример:

Филиал в Екатеринбурге - звонки клиентам региона «Свердловская o область» идут с номеров 7343.

Филиал в Краснодаре - с номеров 7861. o Таким образом, звонки от филиала всегда отображаются как «местные» для клиентов в этом регионе.

3. Для региональных маркетинговых кампаний Когда компания запускает рекламные акции или обзвоны в определённых областях, правило по региону помогает автоматически привязать звонки к нужной аудитории.

Пример:

Акция для Урала → регион «Челябинская область»; o

Акция для Юга → регион «Ростовская область». o

Система сама выберет карусель с номерами нужного региона.

Почему это удобно

● Локальное присутствие: клиенты охотнее отвечают на звонки, если видят местный номер. ● Повышение доверия: звонок с регионального номера воспринимается как обращение «из своего города». ● Увеличение дозвона: вероятность ответа растёт, особенно при обзвонах по холодным базам. ● Автоматизация: сотруднику не нужно ничего выбирать - система сама подставляет правильный номер. ● Простая логика: достаточно один раз указать регион при настройке клиента - правило будет работать всегда.

Советы по настройке

● Создайте отдельные карусели для ключевых регионов, где у вас больше всего звонков. ● Используйте одинаковую структуру именования каруселей (например, «Карусель_Москва», «Карусель_СПБ»). ● При необходимости комбинируйте с правилами по маске - например, когда часть номеров региона не имеет точного кода. ● Если регион не определён, звонок будет выполнен по стандартной автоподстановке. Поэтому полезно добавить резервную универсальную карусель.
