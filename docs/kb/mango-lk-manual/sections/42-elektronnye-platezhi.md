### 2.5.3. Электронные платежи

> Трассировка: PDF §2.5.3 · сквозные стр. 38-39 · источники: ч.1 `kb/sources/mango-lk-manual/LK_manual_v-125-1-280.pdf` с.38-39.

Пополнение счета с помощью электронных платежей возможно благодаря сервисам ЮMoney, QIWI, а также при помощи SMS-сообщений.

Введите цифрами сумму платежа в одноименное поле. Выберите сервис, при помощи которого будет произведена оплата. Нажмите кнопку «Оплатить». В результате будет открыта новая вкладка браузера на странице выбранного

При оплате через SMS-сообщение в поле «Кому» введите короткий номер 3116. В поле, предназначенное для ввода текста, введите сообщение в формате [сервис] [номер счета] [сумма], например, mt 77770000 500.
