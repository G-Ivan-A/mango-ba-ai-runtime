#### 4.6.5.8. Общие настройки

> Трассировка: PDF §4.6.5.8 · сквозные стр. 489 · источники: ч.2 `kb/sources/mango-lk-manual/LK_manual_v-125-281-566.pdf` с.209.

Вкладка предназначена для управления общими параметрами обработки звонков и работы с задачами исходящего обзвона.

Доступные настройки:

 Режим определения номеров из Адресной книги Контакт-центра Определяет, каким образом система сопоставляет входящий номер абонента с записями в адресной книге. o Стандартное — поиск по совпадению последних 7 цифр номера

(рекомендуется для большинства сценариев). o Строгое — поиск по совпадению всех цифр номера. Позволяет

повысить точность отображения при большом количестве похожих номеров (например, 7 925 777-22-33 и 7 915 777-22-33).  Автоматическое завершение заданий из кампании исходящего обзвона Включение этой опции позволяет автоматически закрывать задания, если клиент самостоятельно перезвонил на входящую линию компании и разговор с оператором длился не менее 3 секунд. Это исключает повторный обзвон клиентов, уже вступивших в контакт.
