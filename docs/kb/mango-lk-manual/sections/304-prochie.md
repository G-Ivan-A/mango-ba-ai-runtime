#### 4.6.5.7. Прочие

> Трассировка: PDF §4.6.5.7 · сквозные стр. 488-489 · источники: ч.2 `kb/sources/mango-lk-manual/LK_manual_v-125-281-566.pdf` с.208-209.

Вкладка предназначена для настройки подстановочного ANI (Caller ID), который используется при поступлении звонков с номеров других операторов, подключённых к Виртуальной АТС.

Доступная настройка:

 Подстановочный ANI при поступлении звонка с номеров других операторов Позволяет выбрать номер, который будет отображаться сотрудникам ВАТС в качестве идентификатора вызова (АОН). Это полезно, если звонок поступает от стороннего оператора, но необходимо, чтобы сотрудники видели единый согласованный номер.
