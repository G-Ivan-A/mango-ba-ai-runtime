#### 4.6.3.3. Настройка доступа

> Трассировка: PDF §4.6.3.3 · сквозные стр. 454-455 · источники: ч.2 `kb/sources/mango-lk-manual/LK_manual_v-125-281-566.pdf` с.174-175.

Данный раздел предназначен для создания, редактирования и персонализации ролей пользователей в Личном кабинете (ЛК).

Персонализированное рабочее место: Пользователь ЛК с правом "Изменять права доступа сотрудников" (по умолчанию: Руководитель компании и Администратор) может настроить рабочие места сотрудников на основании их ролей, что позволяет гибко адаптировать доступные функции в ЛК для каждой роли. Все настройки сохраняются в облаке (на сервере MANGO OFFICE), что исключает необходимость ручного конфигурирования на каждом компьютере.

В этом разделе можно просматривать роли, создавать новые роли, изменять права доступа ролей и удалять пользовательские роли.

Роль представляет собой набор прав доступа. Назначение роли пользователю определяет, какие функции системы будут ему доступны.

В этом разделе администратор может:

 просматривать список ролей  создавать новые роли  копировать существующие роли  редактировать существующие роли  удалять пользовательские роли

При создании или редактировании роли определяется набор прав доступа, которые будут доступны пользователям с этой ролью.

внимание

Настройки роли позволяют:

 определять перечень ролей с доступом на изменение;  определять перечень ролей, на которые производится смена доступа;  определять перечень ролей для внесения изменений в их настройки.
