#### Добавление номеров

> Трассировка: PDF §4.5.19.3 · сквозные стр. 418-419 · источники: ч.2 `kb/sources/mango-lk-manual/LK_manual_v-125-281-566.pdf` с.138-139.

Номера используются при исходящих звонках. Чтобы их добавить:

1. Откройте карусель на редактирование. 2. Перейдите на вкладку Номера. 3. Нажмите кнопку Добавить. 4. Выберите нужные (возможна фильтрация и массовый выбор). 5. Подтвердите выбор кнопкой Сохранить.

При редактировании карусели можно использовать до 2000 номеров, при этом рекомендуется оставить не менее двух активных номеров типов DID, DEF или МангоМобайл.

Если из карусели удаляется последний номер, карусель будет деактивирована.
