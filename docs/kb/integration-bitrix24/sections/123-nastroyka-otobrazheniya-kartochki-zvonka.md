| Вариант<br>отображения | Примечание |
| --- | --- |
| При поступлении<br>звонка | Выбран по умолчанию. Карточка отображается<br>одновременно с входящем звонком |
| После начала<br>разговора | Карточка покажется на экране только того, как вы<br>примите входящий звонок (поднимите трубку). |
| Не отображать | Карточка звонка не будет отображаться на экране |
