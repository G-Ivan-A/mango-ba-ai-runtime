# Посмотреть контактные данные собеседника

> Трассировка: PDF §— · сквозные стр. 40 · источники: ч.1 `kb/sources/mtalker/UserGuide_mTalker_4Mobile 11.06.26.pdf` с.40.

Вы можете быстро перейти из чата в карточку вашего собеседника. Будут выведены на экран контактные данные собеседника: имя, фамилия, телефоны, адрес электронной почти и прочее.
