# Удалить участника

> Трассировка: PDF §— · сквозные стр. 44-45 · источники: ч.1 `kb/sources/mtalker/UserGuide_mTalker_4Mobile 11.06.26.pdf` с.44-45.

Вы можете удалить участника из чата, который ранее был создан вами и/или тот чат, в котором вам предоставлены права администратора. Вы НЕ можете удалить участника из чата, в котором вам предоставлены права участника. Для того чтобы удалить участника из чата, на закладке “Чаты” следует: 1) нажмите на строку с названием чата. Будет открыто окно чата; 2) нажмите на заголовок чата. Будут открыты данные чата;
