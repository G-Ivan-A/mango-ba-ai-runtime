# Переименовать чат / канал

> Трассировка: PDF §— · сквозные стр. 44 · источники: ч.1 `kb/sources/mtalker/UserGuide_mTalker_4Mobile 11.06.26.pdf` с.44.

Вы можете переименовать чат, который ранее был создан вами и/или тот чат, в котором вам предоставлены права администратора. Вы НЕ можете переименовать чат, в котором вам предоставлены права участника. Для того чтобы переименовать чат, на закладке “Чаты” следует: 1) нажмите на строку с названием чата. Будет открыто окно чата; 2) нажмите на заголовок чата. Будут открыты данные чата;
