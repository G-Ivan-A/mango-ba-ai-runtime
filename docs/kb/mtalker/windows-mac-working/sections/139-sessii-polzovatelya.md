2) нажать на пункт “Устройства” . Будет отображен список устройств, на которых открыта ваша сессия пользователя. Удаленный выход из MTalker Если вы забыли выйти из MTalker на ПК, к которому у вас уже нет доступа, то сделать это можно удаленно. Чтобы удаленно выйти из MTalker, в списке устройств, на которых открыта ваша сессия пользователя, следует: 1) нажать пиктограмму “Корзина”в строке с данными того или иного устройства, на котором выполнен вход в MTalker. Будет открыто окно “Завершение сессии”; 2) нажать на кнопку “Завершить”. Будет завершена ваше сессия пользователя MTalker на выбранном вами устройстве.
