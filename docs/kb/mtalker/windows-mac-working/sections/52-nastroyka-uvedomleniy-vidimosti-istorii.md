# 5.12. Настройка уведомлений видимости истории чата

> Трассировка: PDF §5.12 · сквозные стр. 58-59 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.58-59.

Вы можете настроить видимость истории чата для новых участников. Можно скрыть всю историю чата от новых участников или разрешить им видеть последние 200 сообщений. Mango Talker для сред ОС Windows и Mac. Руководство пользователя | Версия от 11.06.2026

![Изображение, стр. 59](../images/52-nastroyka-uvedomleniy-vidimosti-istorii-1.png)

Для того чтобы настроить видимость истории чата, в разделе”Чаты” следует: 1. кликнуть на строку с названием целевого чата / канала. Будет открыта история сообщений в данном чате / канале; 2. нажмите на перечень участников чата под названием чата. Будет открыто окно “Информация о чате”;

![Изображение, стр. 59](../images/52-nastroyka-uvedomleniy-vidimosti-istorii-2.png)

3. в поле “Уведомления” деактивируйте переключатель , чтобы отключить показ уведомлений в этом общем чате или канале. И наоборот, если надо включить показ уведомлений - активируйте переключатель “Уведомления”.
