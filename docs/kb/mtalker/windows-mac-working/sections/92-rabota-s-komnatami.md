1) наведите курсор на строку с названием комнаты и вызовите контекстное меню; 2) выберите пункт “Заказать обратный звонок”. Будет открыто окно “Обратный звонок”; 3) в поле “Ваш телефон” укажите ваш номер телефона; 4) в поле “Абонент” будет указан номер комнаты, выбранной вами на шаге 1; 5) нажмите кнопку “Заказать звонок”. Будет выполнен звонок на номер, указанный в поле “Ваш номер”; 6) после того, как вызываемый абонент примет звонок, будет выполнен звонок на номер, указанный в поле “Абонент”; 7) после того, как второй абонент пример звонок, будет установлено соединение между абонентами.
