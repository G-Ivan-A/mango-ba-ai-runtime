# 10.1. Общие сведения

> Трассировка: PDF §10.1 · сквозные стр. 100 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.100.

Функция MTalker “История вызовов” позволяет оперативно получать информацию о том, кто и когда звонил ранее. В истории вызовов содержатся записи о звонках, прошедших через вашу SIP-учетную запись ВАТС и номер мобильного телефона (при его регистрации на ВАТС). История вызовов содержит разделы: • Все вызовы: в этот раздел вносятся все записи о звонках (пропущенные, входящие и т.д.). • Пропущенные: в этот раздел вносятся записи о пропущенных звонках; • Записи разговоров: в этот раздел вносятся записи о звонках, которые были записаны в файл, который вы можете прослушать; • Голосовая почта: в этот раздел вносятся записи голосовой почты. В общем случае, запись о звонке содержит следующие данные: • имя звонившего (загружается из телефонной книги при наличии); • номер телефона либо SIP ID;
