# Журнал передач SSOT

Каталог `ssot/` хранит закреплённые побайтные копии SSOT из других
репозиториев (RFC-RT-002, Р-RT-6; раздел 12 RFC-RT-003 спицы промптов).
SSOT остаётся в источнике: runtime копию хранит, исполняет и не правит.

| Путь | Что |
| --- | --- |
| `ssot/mango_ba_prompts/<путь в спице>` | артефакты манифеста передачи, побайтно с `source_commit`; других файлов в каталоге нет |
| `ssot/mango_ba_prompts.manifest.json` | копия манифеста передачи: состав, sha256, статусы цепочки |
| `ssot/mango_ba_prompts.link-map.json` | копия карты ссылок: куда ведёт ссылка из копии на цель вне передачи |
| `ssot/TRANSFERS.md` | этот журнал |

## Правила

1. **Копию не править.** Ни один байт в `ssot/` не меняется вручную, в том
   числе ссылки и концы строк (`.gitattributes`: `ssot/** -text`).
   Расхождение со спицей устраняется следующей передачей.
2. **Одна передача — один PR и одна строка журнала.** Передача приходит
   целиком: новый манифест с новым `source_commit`, каталог
   `ssot/mango_ba_prompts/` заменяется полностью. Частичная копия запрещена.
3. **Fail-closed.** Копию делает `tests/build_ssot_transfer.py`: он
   собирает её во временном каталоге, сверяет и только после этого заменяет
   `ssot/`. При любом расхождении `ssot/` не меняется.
4. **Ссылки (Р-RT-7 = 7а).** Ссылка на файл передачи работает без правки:
   пути источника сохранены. Цель вне передачи разрешается по
   `ssot/mango_ba_prompts.link-map.json` на permalink спицы; без доступа к
   спице — `ACCESS_GAP`.
5. **Журнал без содержимого.** Здесь — только пути, счёт и sha256.
6. **Откат** — revert PR передачи: процессы этапа 1 возвращаются в
   `BLOCKED`.

Сторож `tests/test_ssot_transfer.py` проверяет без сети и без доступа к
спице: набор файлов равен манифесту, sha256 каждого файла равен манифесту,
sha256 копий манифеста и карты ссылок равен последней строке журнала, ссылки
из копии ведут в файлы копии или записаны в карте ссылок, `sources` карты
гейтов совпадают с манифестом.
