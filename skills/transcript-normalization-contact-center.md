# Навык: нормализация текста сессии выявления

## Когда применять

Вход — `A-IN` в состоянии `raw` (расшифровка, письмо, заявка); выход — тот же
`A-IN`, приведённый к форме, пригодной для разметки, без потери атрибуции реплик
и без единого нового утверждения.

## Предусловия

1. Продуктовый класс объявлен во входе (`products[].product_class`). Класс не
   выводится из текста: если поле пусто — отказ, см. раздел «Отказ».
   Функция продукта (`products[].atomic_function`) — id узла `level: function`
   каталога `taxonomy/mango-products.yaml`, в `classes` которого входит
   объявленный класс; функция из текста не выводится и не подбирается.
2. Входной артефакт объявлен как `A-IN`, состояние `raw`.
3. Каждому фрагменту входа сопоставлен идентификатор источника `SRC-NN` с
   разрешимым локатором (документ, раздел, страница или таймкод).

## Шаги

1. `normalize-text` — убери шум расшифровки (заполнители речи, повторы
   распознавания, технические маркеры), сохранив: кто говорит, в каком порядке,
   с каким таймкодом. Формулировки говорящего не переписываются: перефразировка
   уничтожает цитату, на которую опирается вся дальнейшая проверка источников.
2. `deduplicate-items` — слей дословные повторы одной и той же реплики, записав
   для каждого слияния, какие фрагменты объединены и какой локатор сохранён.
3. `check-schema` — проверь результат против `contracts/c-in.md`. Для каждой
   записи `products[]` найди в `taxonomy/mango-products.yaml` узел с `id`,
   равным `atomic_function`: узла нет, его уровень не `function` или
   `product_class` записи не входит в его `classes` — отказ (раздел «Отказ»),
   а не замена значения близким id каталога.

## Обязательные слоты выхода

| Слот | Каноническая подпись | Обязательность | Причина пустоты |
| --- | --- | --- | --- |
| `sources[]` | Источники | обязателен | нет: без источника вход не принимается |
| `sources[].locator` | Локатор источника | обязателен | нет |
| `sources[].content` | Нормализованный текст | обязателен | нет |
| `products[]` | Реестр продуктов задачи | обязателен | нет |
| `merges[]` | Журнал слияний | обязателен, пуст при отсутствии дублей | «дублей не обнаружено» |

## Самопроверка (G-self)

- Каждая реплика выхода сохранила говорящего и локатор — да/нет.
- Ни одно утверждение выхода не отсутствует во входе — да/нет.
- Число слияний равно числу записей в журнале слияний — да/нет.
- Выход соответствует `contracts/c-in.md` — да/нет.
- Каждая `atomic_function` — id функции каталога `taxonomy/mango-products.yaml`
  объявленного класса — да/нет.
- Формулировки говорящего не перефразированы — да/нет.

## Отказ

Остановись и верни вопрос человеку, если:

- продуктовый класс не объявлен во входе (правило `PT-1`: класс объявляется до
  начала шага и не выводится из текста);
- функция продукта вне каталога `taxonomy/mango-products.yaml` или функция
  чужого класса (правило 1 `AGENTS.md`): вернуть объявленное значение, класс
  и вид непокрытого случая — «функция вне каталога», «уровень каталога не
  функция» или «функция чужого класса»; новое значение не изобретается;
- вход не является текстом (аудио, изображение, таблица без текстового слоя);
- у фрагмента нет разрешимого локатора: нормализованный текст без локатора
  делает невозможной проверку цитат на следующих узлах маршрута.
