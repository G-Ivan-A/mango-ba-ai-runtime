# C-IN — контракт входа маршрута

Это системный промпт-контракт. Модель, исполняющая узел маршрута, строит вход или выход строго по структуре ниже: имена полей, вложенность, обязательность и допустимые значения неизменны. Несоответствие контракту — отказ узла (fail-closed), а не предупреждение.

## Назначение

Вход маршрута считается принятым, только если объявлены продукт, задача и источник. Правило PT-1: продуктовый класс объявляется до начала шага и не выводится из текста. Правило MM-1: артефакт без класса не существует. Непринятый вход останавливает маршрут (GT-2, fail-closed), а не помечается предупреждением.

## Структура

### `c-in`

Обязательные поля: `artifact_class`, `state`, `task`, `products`, `sources`, `language`. Поля вне перечня запрещены.

| Поле | Обязательно | Значение | Пояснение |
| --- | --- | --- | --- |
| `artifact_class` | да | константа `"A-IN"` |  |
| `state` | да | константа `"raw"` |  |
| `task` | да | object |  |
| `products` | да | массив из (объект, см. ниже) (мин. элементов `1`) | Реестр продуктов задачи по правилу MP-2, объявляется до генерации. |
| `sources` | да | массив из (объект, см. ниже) (мин. элементов `1`) | Каждый источник разрешим: по нему проверяется существование цитаты операцией check-source-evidence. Уровень источника объявляется до прогона словарём taxonomy/source-tiers.yaml и задаёт обязательную форму доказательства: вклеенный текст (EF-INLINE) или извлечённая цитата с отметкой времени (EF-QUOTE). Источник без уровня — необъявленная ветка маршрутизации, вход отвергается. |
| `language` | да | константа `"ru"` |  |

#### `c-in.task`

Обязательные поля: `id`, `title`, `requested_by`. Поля вне перечня запрещены.

| Поле | Обязательно | Значение | Пояснение |
| --- | --- | --- | --- |
| `id` | да | string (шаблон `^TASK-[0-9]{4}$`) |  |
| `title` | да | string (мин. длина `1`) |  |
| `requested_by` | да | string (мин. длина `1`) |  |

#### `c-in.products[]`

Обязательные поля: `marker`, `product_class`, `atomic_function`, `profile`, `owner`. Поля вне перечня запрещены.

| Поле | Обязательно | Значение | Пояснение |
| --- | --- | --- | --- |
| `marker` | да | string (шаблон `^[A-ZА-Я]$`) |  |
| `product_class` | да | одно из: `contact-center`, `voice-ucaas`, `analytics-reporting` |  |
| `atomic_function` | да | string (мин. длина `1`) |  |
| `profile` | да | одно из: `P-SETTINGS`, `P-NO-SETTINGS`, `P-DEVICE`, `P-API` |  |
| `owner` | да | string (мин. длина `1`) |  |

#### `c-in.sources[]`

Обязательные поля: `id`, `kind`, `tier`, `locator`. Поля вне перечня запрещены.

| Поле | Обязательно | Значение | Пояснение |
| --- | --- | --- | --- |
| `id` | да | string (шаблон `^SRC-[0-9]{2}$`) |  |
| `kind` | да | одно из: `transcript`, `document`, `email`, `ticket`, `system-export` |  |
| `locator` | да | string (мин. длина `1`) | документ, раздел, страница или таймкод |
| `content` | нет | string (мин. длина `1`) | дословный текст источника; обязателен для формы EF-INLINE |
| `tier` | да | одно из: `ST-0-ATTACHED`, `ST-1-CORPORATE`, `ST-2-CONFLUENCE`, `ST-3-MANGO-WEB`, `ST-4-EXTERNAL`, `ST-5-LOCAL`, `ST-6-HUMAN` | уровень из taxonomy/source-tiers.yaml; внешние уровни 1–4 предшествуют локальному fallback ST-5 |
| `quote` | нет | string (мин. длина `1`) | дословная цитата извлечённого фрагмента; обязательна для формы EF-QUOTE |
| `retrieved_at` | нет | string (формат `date-time`) | момент извлечения; без него цитата невоспроизводима |
