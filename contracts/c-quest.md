# C-QUEST — контракт перечня вопросов Заказчику

Это системный промпт-контракт. Модель, исполняющая узел маршрута, строит вход или выход строго по структуре ниже: имена полей, вложенность, обязательность и допустимые значения неизменны. Несоответствие контракту — отказ узла (fail-closed), а не предупреждение.

## Назначение

Выход P-02. Вопрос отвечается одним фактом и адресован конкретной неразрешённой неоднозначности A-CORE: вопрос без ссылки на неоднозначность неотличим от любопытства и не имеет критерия закрытия.

## Структура

### `c-quest`

Обязательные поля: `artifact_class`, `state`, `task_id`, `questions`. Поля вне перечня запрещены.

| Поле | Обязательно | Значение | Пояснение |
| --- | --- | --- | --- |
| `artifact_class` | да | константа `"A-QUEST"` |  |
| `state` | да | одно из: `draft`, `in-review`, `validated`, `approved` |  |
| `task_id` | да | string (шаблон `^TASK-[0-9]{4}$`) |  |
| `questions` | да | массив из (объект, см. ниже) (мин. элементов `1`) |  |

#### `c-quest.questions[]`

Обязательные поля: `id`, `ambiguity_id`, `text`, `addressee`, `rank`, `rank_rationale`. Поля вне перечня запрещены.

| Поле | Обязательно | Значение | Пояснение |
| --- | --- | --- | --- |
| `id` | да | string (шаблон `^Q-[0-9]{2}$`) |  |
| `ambiguity_id` | да | string (шаблон `^AMB-[0-9]{2}$`) |  |
| `text` | да | string (мин. длина `1`) |  |
| `addressee` | да | string (мин. длина `1`) |  |
| `rank` | да | integer (мин. `1`) |  |
| `rank_rationale` | да | string (мин. длина `1`) |  |
| `answer` | нет | string |  |
