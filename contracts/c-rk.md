# C-RK — контракт маршрута и его прослеживаемости

Это системный промпт-контракт. Модель, исполняющая узел маршрута, строит вход или выход строго по структуре ниже: имена полей, вложенность, обязательность и допустимые значения неизменны. Несоответствие контракту — отказ узла (fail-closed), а не предупреждение.

## Назначение

Схема листа прогона (run sheet): проекции графа маршрута на конкретное исполнение. Журнал событий append-only: запись о пройденном узле не редактируется, исправление добавляется новой записью. Лист прогона заменяет свободный файл памяти проекта — состояние прогона обязано быть машиночитаемым.

## Структура

### `c-rk`

Обязательные поля: `run_id`, `route_id`, `task_id`, `started_at`, `events`. Поля вне перечня запрещены.

| Поле | Обязательно | Значение | Пояснение |
| --- | --- | --- | --- |
| `run_id` | да | string (шаблон `^RUN-[0-9]{4}$`) |  |
| `route_id` | да | string (мин. длина `1`) |  |
| `task_id` | да | string (шаблон `^TASK-[0-9]{4}$`) |  |
| `started_at` | да | string (мин. длина `1`) |  |
| `finished_at` | нет | string |  |
| `outcome` | нет | одно из: `completed`, `refused`, `escalated`, `in-progress` |  |
| `events` | да | массив из (объект, см. ниже) (мин. элементов `1`) |  |

#### `c-rk.events[]`

Обязательные поля: `seq`, `node`, `skill`, `actor`, `verdict`, `at`. Поля вне перечня запрещены.

| Поле | Обязательно | Значение | Пояснение |
| --- | --- | --- | --- |
| `seq` | да | integer (мин. `1`) |  |
| `node` | да | string (мин. длина `1`) |  |
| `skill` | да | string (мин. длина `1`) |  |
| `actor` | да | одно из: `agent`, `human` |  |
| `verdict` | да | одно из: `pass`, `reject`, `refused`, `skipped` |  |
| `gate` | нет | одно из: `G-self`, `G-mach`, `G-human` |  |
| `attempt` | нет | integer (мин. `1`, макс. `2`) | после отказа G-mach допустима ровно одна корректирующая попытка; вторая эскалирует на G-human |
| `decision` | нет | string | выбранное ребро и предикат, по которому оно выбрано |
| `rationale` | нет | string |  |
| `artifact_ref` | нет | string |  |
| `at` | да | string (мин. длина `1`) |  |
