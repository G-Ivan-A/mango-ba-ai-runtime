# Mango BA AI Runtime — MVP BCREQ 0.4

Самодостаточный Execution Package для маршрута `A-IN → A-CORE → A-BCREQ` в
GigaCode. Итоговый бизнес-требование сохраняется Markdown-файлом в `runs/`.
Доступ к репозиторию Хаба во время выполнения не нужен.

## Первый запуск

1. Откройте [быстрый старт](docs/guides/00-quick-start.md).
2. Проверьте пакет без Python:

   ```sh
   sh tools/validate-package.sh
   ```

3. Создайте новый чат GigaCode для новой задачи и вставьте пример из быстрого
   старта. Один чат соответствует одной задаче.
4. Найдите результат в `runs/<RUN-ID>/A-BCREQ.md`.

Все инструкции: [docs/guides/README.md](docs/guides/README.md).

## Состав

| Путь | Назначение |
| --- | --- |
| `AGENTS.md` | загрузочный контракт агента |
| `.hub-profile.json` | профиль GigaCode, навыки, маршрутизация и выход |

| `templates/`, `golden/`, `evaluation/` | шаблоны, эталоны и гейты |

| `docs/guides/` | пошаговые инструкции для пользователя |
| `runs/` | листы прогонов и итоговые Markdown-файлы |

## Маршрутизация знаний

Порядок: корпоративная БЗ → Confluence → публичные ресурсы Манго → внешние
системы → локальная копия `docs/kb` → вопрос человеку. Локальная БЗ — только
fallback. В поставляемом профиле уровни 1–4 имеют `out_of_slice`, потому что
URL и доступы не переданы; причина каждого пропуска записана явно.
