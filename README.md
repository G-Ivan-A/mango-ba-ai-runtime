> Чистый Spoke-репозиторий для опытной эксплуатации проектной мета-модели БА v2.1.
> Содержит **только Execution Package** — полностью самодостаточный набор исполняемых контрактов, навыков и правил.
> **Критическое ограничение:** репозиторий спроектирован для автономного исполнения в изолированной среде (например, GitVerse) **без доступа к Хабу**. Любые ссылки на исследовательские документы Хаба в исполняемых артефактах запрещены.
> **Не содержит** legacy-промптов, исторических прогонов или исследовательских документов.

## Назначение
Репозиторий является площадкой практической отладки на пути к Agentic Engineering. Здесь мета-модель БА переводится из теоретической плоскости в исполняемую среду. 

Принцип: **Hub = SSOT для развития, Spoke = Self-contained Execution Package для исполнения**. Spoke не зависит от Хаба в момент runtime.
