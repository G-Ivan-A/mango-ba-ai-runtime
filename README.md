> Чистый Spoke-репозиторий для опытной эксплуатации проектной мета-модели БА v2.1.
> Представляет собой **скомпилированный Execution Package** — полностью самодостаточный набор исполняемых контрактов, навыков (Skills) и правил для автономной работы ИИ-агентов.
> **Архитектурный принцип (Runtime Independence):** Репозиторий спроектирован так, чтобы агент мог выполнить сквозной маршрут (от `A-IN` до целевого артефакта) **без необходимости чтения исследовательских документов Хаба**. Весь необходимый контекст инлайнится или поставляется в машиночитаемом виде.
> **Не содержит:** legacy-промптов, исторических логов прогонов или теоретических исследований.

## Назначение
Репозиторий реализует **Петлю реализации (Implementation Loop)** в парадигме AI-PDLC. Здесь мета-модель БА переводится из теоретической плоскости (Hub) в исполняемую среду (GigaCode/GitVerse).

### Что здесь есть (Execution Package)
- Проектный `AGENTS.md` — точка входа и корневой контракт для ИИ-агента.
- `.hub-profile.json` — конфигурация среды и декларация каталогов.
- `ai/` — скомпилированные исполняемые контракты:
  - `rules/` — правила работы агента и границы делегирования (Bounded Delegation).
  - `skills/` — навыки-подпроцессы для вертикального среза MVP.
  - `commands/` — команды, инициируемые человеком (опционально).
- `golden-set/` — позитивные и негативные эталоны для машинной валидации (`G-mach`).
- `runs/` — логи прогонов и артефакты памяти (`A-MEMORY`).

### Чего здесь нет (и не будет)
- Исследовательских документов, полных таксономий и ADR — они живут в Хабе (SSOT для развития).
- Legacy-артефактов из `mango_ba_prompts`.

## Связь с экосистемой
| Репозиторий | Роль в AI-PDLC |
| --- | --- |
| `hybrid-Intelligence-lab` | **Хаб (SSOT)**: Петля намерения (Intent Loop). Методология, таксономии, исследования. |
| `mango-ba-ai-runtime` | **Spoke (Runtime)**: Петля реализации (Implementation Loop). Скомпилированный Execution Package. |
| `mango_ba_prompts` | **Legacy**: Исторические промпты, не используется для новой модели. |

**Принцип синхронизации:** Hub = источник истины для *развития* модели. Spoke получает скомпилированный контракт через механизмы сборки, оставаясь полностью самодостаточным в момент *исполнения*.
