# mango-ba-ai-runtime

> Чистый Spoke-репозиторий для опытной эксплуатации проектной мета-модели БА v2.1 в среде GigaCode.
> Содержит только **Execution Package** — исполняемые контракты, навыки и правила для запуска задач.
> **Не содержит** legacy-промптов, исторических прогонов или исследовательских документов.

## Назначение

Репозиторий является **площадкой практической отладки** на пути к стратегической цели экосистемы — **Agentic Engineering**. Здесь мета-модель БА, стабилизированная в Хабе, переводится из теоретической плоскости в исполняемую среду GigaCode.

### Что здесь есть
- Проектный `AGENTS.md` — точка входа для любого ИИ-агента.
- `.hub-profile.json` — конфигурация среды и декларация каталогов.
- `ai/` — исполняемые контракты:
  - `rules/` — правила работы агента (наследуются из Хаба).
  - `skills/` — навыки-подпроцессы для вертикального среза MVP.
  - `commands/` — команды, вызываемые человеком (опционально).
- `golden-set/` — позитивные и негативные эталоны для `G-mach`.
- `runs/` — логи прогонов и артефакт памяти (`A-MEMORY`, если внедрён).

### Чего здесь нет (и не будет)
- Исследовательских документов и полных таксономий — они живут в Хабе.
- Legacy-промптов и исторических прогонов из `mango_ba_prompts`.
- Дублирования нормативных документов Хаба — только ссылки на SSOT.

## Связь с экосистемой

| Репозиторий | Роль |
| --- | --- |
| [`hybrid-Intelligence-lab`](https://github.com/G-Ivan-A/hybrid-Intelligence-lab) | **Хаб (SSOT)** — методология, таксономии, исследования, стандарты, ADR |
| `mango-ba-ai-runtime` | **Spoke (Runtime)** — исполняемые контракты для GigaCode |
| `mango_ba_prompts` | **Legacy** — исторические промпты и прогоны, не используется для новой модели |

Принцип: **Hub = SSOT, Spoke = Execution Package**. Любое изменение методологии происходит в Хабе; Spoke получает скомпилированный контракт через механизмы синхронизации.

## Точка входа для агента

🛫 **Новый агент? Начни здесь → `AGENTS.md`**

Это обязательный предполётный протокол. Любой ИИ-агент обязан прочитать его **до** первого изменения файлов.

## Индустриальный контекст

Архитектура репозитория опирается на практики 2026 года (отчёт АФТ «ИИ-трансформация разработки»):
- **Spec-Driven Development (SDD)** — спецификация как главный артефакт, код производен.
- **AI-PDLC** — разделение на Петлю намерения (Hub/Человек) и Петлю реализации (Spoke/Агент).
- **Bounded Delegation** — чёткие границы автономности агента, предотвращение «похмелья вайб-кодинга».
- **Токеномика** — управление бюджетом и лимитами контекста как часть контракта.
