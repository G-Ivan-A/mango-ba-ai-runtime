# A-BCREQ — тест локального исполнения

- Task: `TASK-0001`
- Run: `RUN-0001`
- Projection: `V-BIZ`
- Product class: `contact-center`
- Status: `approved`

## Аннотация

Минимальный воспроизводимый прогон подтверждает, что итог маршрута сохраняется
Markdown-файлом в `runs/`, а недоступные уровни источников отмечаются
`out_of_slice` до использования локального fallback.

## Бизнес-цель

Подтвердить самодостаточность Execution Package без доступа к Хабу.

## Проблема

Без тестового артефакта невозможно проверить контракт пути результата.

## Заинтересованные стороны

БА-аналитик и владелец runtime.

## Текущее состояние

Пакет развёрнут локально; внешние источники не настроены.

## Целевое состояние

Валидный результат существует по пути `runs/RUN-0001/A-BCREQ.md`.

## Описание решения

Выполнить переносимый G-mach и сохранить тестовый A-BCREQ в `runs/`.

## Границы

Тест не подтверждает сетевую интеграцию GigaCode и внешних источников.

## Бизнес-правила

Локальная БЗ применяется только после уровней 1–4 либо их явного
`out_of_slice`.

## Данные

Используются идентификаторы TASK-0001 и RUN-0001.

## Интеграции

Нет по тестовому сценарию.

## Ограничения

Python и PyYAML не требуются.

## Риски

Реальная интеграция GigaCode требует проверки в корпоративной среде.

## Критерии приёмки

1. `sh tests/runtime-smoke.sh` завершается с кодом 0.
2. `sh tools/validate-package.sh` завершается с кодом 0.
3. Этот файл находится в `runs/RUN-0001/`.
